  add a small Feature::isEnabled() helper. assign and isAccessibleBy could then
  both use it, so the flag is checked in one place. I haven't built that. Do you
  want me to?

● The feature model now makes both decisions, and the full suite passes (21
  tests).

  - Feature::isEnabled() returns the global enabled flag.
  - Feature::isEnabledFor(?User $user) replaces isAccessibleBy. It returns false
    for a null user or a disabled feature, and otherwise checks whether the
    user is assigned.
  - FeatureEnabled middleware now checks in this order:
    a. 404 if the feature isn't found.
    b. 403 "Feature is globally disabled." if isEnabled() is false. It reads
       user_id after this check, so a disabled feature never touches the user.
    c. 403 "No user provided." if user_id is missing.
    d. 403 "Feature not enabled for this user." if
       isEnabledFor(User::find($userId)) is false.
  - FeatureController::assign uses isEnabled() again, so every enabled check now
    goes through the model.

  isEnabledFor still checks isEnabled() itself, so it stays correct if it's
  called without the middleware.
